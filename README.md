# 끝없는 검로

이펙트와 타격감에 집중한 방치형 웹 게임입니다. 설치 없이 브라우저에서 바로 플레이할 수 있습니다.

**플레이:** https://hical3111-pixel.github.io/original/

## 특징
- 히트스톱, 화면 흔들림, 균열, 컷인, 파티클로 만든 타격감
- 모든 스킬이 짝을 이루는 연계기: 시작 스킬을 쓰면 마무리 스킬이 준비되고, 이어 쓰면 연계기가 발동
- 게이지로 쓰는 각성기(여러 개 중 선택), 스킬별 각성 분기
- 보스 등장 컷신, 2페이즈, 결정타 연출, 공격 패턴과 타이밍 패링
- 일일 도전, 유물 뽑기, 궁수·마법사 동료, 업적과 칭호, 환생
- 브라우저 자동 저장, 오프라인 보상

현재 스킬·연계기 목록은 [AGENTS.md](AGENTS.md) 8장에 있습니다.

## 조작
- 기사는 자동으로 싸웁니다. 화면을 누르면 직접 베어 추가 피해를 줍니다.
- 보스 공격 직전 금색 원이 줄어들 때 누르면 패링합니다.

## 파일 구성
- `index.html`: 화면 구성과 스타일
- `core.js`: 상태, 스탯, 전투, 몬스터
- `skills.js`: 스킬, 연계기, 각성, 유물 상자
- `main.js`: 게임 루프, 렌더링, 보스 패턴, UI
- `selftest.js`: 구조 자가 점검 (`?selftest`로 실행)

개발 규칙과 설계 방향은 [AGENTS.md](AGENTS.md)에 있습니다.
